# Tech Stack

| Technology         | Purpose         | Why                                                |
| ------------------ | --------------- | -------------------------------------------------- |
| **Next.js 15**     | Framework       | React framework with API routes, SSR, and great DX |
| **React 19**       | UI library      | Component-based UI, widely supported               |
| **TypeScript**     | Type safety     | Catches errors early, better maintainability       |
| **Tailwind CSS 4** | Styling         | Utility-first, fast development, consistent design |
| **ESLint**         | Code quality    | Enforces coding standards, catches bugs            |
| **Prettier**       | Code formatting | Consistent style across the codebase               |
| **Turbopack**      | Dev bundler     | Fast development server (Next.js default)          |
| **npm**            | Package manager | Standard, reliable, widely used                    |
| **Git / GitHub**   | Version control | Code history, collaboration, backups               |
